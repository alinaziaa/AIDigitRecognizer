# AIDigitRecognizer 🤖

## AI-Based Handwritten Digit Recognition Android Application

AIDigitRecognizer is an AI-based Android application that recognizes handwritten digits from **0 to 9**. Users can draw a digit on the screen, and the application uses a TensorFlow Lite machine learning model to predict the digit.

## ✨ Features

- 🚀 Professional Splash Screen
- 🔐 Login Screen with Email and Password
- 👁️ Show/Hide Password Feature
- 📝 User Registration Screen
- 🏠 Dashboard with Easy Navigation
- ✍️ Handwritten Digit Recognition (0–9)
- 🧠 TensorFlow Lite Model Integration
- 🧹 Clear Drawing Function
- 📊 Prediction Result Display
- 🎨 Modern Dark UI with Cyan Accents

## 🛠️ Technologies Used

- **Language:** Java
- **UI Design:** XML
- **IDE:** Android Studio
- **Machine Learning:** TensorFlow Lite
- **Model:** MNIST-based digit recognition model

## ⚙️ How It Works

1. Open the AIDigitRecognizer application.
2. Navigate through the login screen to the dashboard.
3. Open the Digit Recognition screen.
4. Draw a digit between 0 and 9 on the canvas.
5. Tap the Recognize button.
6. View the predicted digit and confidence result.
7. Clear the canvas to try another digit.

## 📱 Application Modules
